# 🎶 SQL Music Store Analysis

This project demonstrates how SQL can be applied to analyze a **digital music store database**.  
It simulates real-world business intelligence tasks like identifying top-selling tracks, analyzing customer spending patterns, and evaluating employee performance.  

---

## 📌 Project Objectives

- Understand the music store database schema  
- Write SQL queries to answer business-related questions  
- Perform **customer, sales, and product analytics**  
- Strengthen SQL fundamentals with a hands-on project
